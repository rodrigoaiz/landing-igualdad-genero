# Moodle para Igualdad de Género

Base documental para una landing de orientación dirigida al alumnado del Colegio de Ciencias y Humanidades (CCH) que utiliza Moodle en la asignatura de Igualdad de Género.

## Propósito

Ayudar al alumnado a ingresar a Moodle, localizar la asignatura y realizar las acciones más frecuentes mediante videotutoriales breves, claros, accesibles y fáciles de consultar desde computadora o celular.

## Público principal

Estudiantes del CCH inscritos en la asignatura de Igualdad de Género, especialmente quienes tienen poca experiencia usando Moodle.

## Objetivos de aprendizaje

Al terminar de consultar los tutoriales, el estudiante podrá:

- ingresar a Moodle e iniciar sesión;
- localizar la asignatura de Igualdad de Género;
- entregar, verificar y modificar actividades;
- participar y responder en foros;
- contestar cuestionarios y actividades H5P;
- consultar su avance, calificaciones y retroalimentación;
- realizar las principales acciones desde un dispositivo móvil.

## Alcance inicial

El sitio será una landing de una sola página con navegación por anclas. Cada tutorial tendrá una ficha individual y un reproductor de video. No sustituirá a Moodle ni explicará contenidos académicos de la asignatura: funcionará como guía para usar la plataforma.
